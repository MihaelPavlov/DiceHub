Component redesign

The notification bubble

The floating, draggable notification button (assistive-touch.component) currently renders as a flat blue rounded square with a Material bell icon, and swaps to an external GIF — a bell with a red alert badge — when a notification is active. It's the one piece of chrome visible on every single screen, and it never got touched by the redesign. This proposes bringing it in line — same rounded-pill language, same stroke icons, same blue-primary + coral-badge system as everywhere else — while keeping the thing that GIF was actually doing: an animation that keeps drawing the eye until you notice it. That's now a live CSS ring on the bell and a breathing pulse on the badge, instead of a swapped-in raster loop.

States

Same button, four things it needs to communicate: nothing to see, something new, muted because permissions are off, and faded out after a few seconds idle — matching the real buttonOpacity behavior already in the component.

Default Nothing new. Bell only.
Unread The bell keeps giving a little ring, and the coral dot keeps breathing — live CSS now, not a raster loop.
