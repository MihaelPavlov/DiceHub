Gamification · Animation Audit v2

Only animate what's actually there

A correction pass on the first version of this page. Every card below is grounded in a real component, a real CSS class, and — where one already exists — the real current animation, cited by file. Nothing here assumes a feature the app doesn't have.

What got cut and why: the first version had a "Level up / XP burst" idea (profile) and a "leaderboard rank climbs +2" idea. Neither exists — there's no XP/level system anywhere in the codebase (only a RewardLevel enum for reward tiers, unrelated), and the leaderboard never stores a previous rank, so there's no delta to animate. Both are dropped below, replaced with real mechanics that do the same emotional job.

07 · Finding yourself

Rank-row highlight on scroll

leaderboard-challenges.component.ts · scrollToCurrentUser()  /  streak-leaderboard.component.ts
Now: both leaderboards have a real, working scrollToCurrentUser() — tapping the "your rank" card scrolls the list to #user-rank-<username>.
