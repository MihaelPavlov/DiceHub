Notifications Turn on notifications so you never miss a reservation update or event reminder.
Android · Unblock notifications
3 steps
1
When DiceHub is installed, open it once and accept the browser's Allow notifications prompt.
2
If you missed it, go to Settings → Apps → DiceHub → Notifications and turn the toggle on.
3
Reservation and event reminders now arrive even when DiceHub is closed.
iOS · Unblock notifications
3 steps
1
Notifications on iOS only work after DiceHub is added to your home screen — install it first.
2
Open the installed app once and accept the Allow Notifications prompt when it appears.
3
If you missed it, enable it from Settings → DiceHub → Notifications.
