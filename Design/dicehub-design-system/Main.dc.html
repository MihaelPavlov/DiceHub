Accents

Four hues, each with a solid form (icons, headings, primary actions) and a low-opacity "soft" form (icon tiles, badges, status fills). Hue carries meaning loosely — amber for primary/energy, coral for danger/urgent, teal for success/positive, violet for a secondary highlight.

Typography

Bricolage Grotesque carries display type — headings, numerals, anything that should feel a little more crafted. Sora is the body face, used at 400–700 for copy, labels and UI text.
